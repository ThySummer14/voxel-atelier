# 晒秋 · 篁岭九月

体素作品:徽州篁岭的秋日午后——白墙黛瓦的山村台地上,家家户户的晒匾里摊晒着红辣椒、黄菊、柿饼与白果干,炊烟从屋后升起,山间秋林红金成片,桥上挑担人正走过溪去。

## 看点

- **原创题材**:晒秋(未被走过暖色白昼烟火气方向)
- 三层石砌台地 + 依山错落的徽派民居:南向阶梯**马头墙**正对镜头,压顶瓦线
- 十九面**晒匾**阵列(红为绝对主角),竹晒架、玉米串、辣椒串挂晒
- 后山秋林低频色块成片(红/橙/金),两端沉入地平;两重远山青灰
- 溪、石拱桥(拱洞下水流)、石阶、金黄稻田与稻草垛、渡口草滩
- 活物:桥上挑担人、晒场翻椒人、屋脊花猫、鸡、狗
- 动画:三缕炊烟循环上升、五团体素云缓移、三只飞鸟绕场
- 交互:拖拽旋转 / 滚轮远近(惯性阻尼轨道相机)

## 操作

拖拽旋转,滚轮缩放。URL 参数:`?view=yaw,pitch,dist` 设定初始机位;`?probe=N` 为调试探针(默认关闭)。

## 运行

任意静态服务器:

```bash
python3 -m http.server 8347
# 打开 http://localhost:8347
```

## 技术要点(自研体素管线)

- 稀疏 Map 体素世界,单次网格化:六向面剔除 + **逐顶点 AO**(对角翻转防插值瑕疵)
- 竖直面 AO 跳过"下侧邻居":阶梯坡面(屋瓦/山坡)不被下一阶系统性压暗
- 顶点色按 sRGB→linear 转换(`THREE.Color.setHex`),避免二次提亮
- three r155+ 物理光照 Lambert 按 1/π 衰减:**光强需按 legacy 直觉 ×π**(sun 8.2 / hemi 3.1 / fill 1.0)
- PCFSoft 阴影 4096、normalBias 1.4、bias -0.0002,shadow camera 覆盖全场
- 确定性坐标 hash 色抖动(刷新画面一致),低频 patch 噪声让秋林成片
- 体素规模 ~100 万,单 mesh 单 draw call
