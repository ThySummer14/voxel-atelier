# 上河虹桥 · The Rainbow Bridge

清明上河图「虹桥段」的体素转译。暖阳午后的汴河两岸：无柱木拱虹桥横跨，
漕船正在放桅过桥，桥上人群凭栏围观，两岸摊棚伞色斑驳，垂柳拂水，城楼在雾中。

> 前作《浮岛茶庭》《琉璃浮屠》等六件均为"冷色夜景+灯火"套路；
> 本作是系列中第一件**白昼市井烟火**作品，也是工艺上第一次做到
> 真实太阳阴影（4096 PCFSoft）+ 正确线性色彩管线 + 逐体素 AO。

## 打开方式

```bash
cd 上河虹桥
node .serve.cjs          # 或 python3 -m http.server 8341
# 浏览器打开 http://localhost:8341
```

纯静态、零依赖、零远程请求（three r160 已本地 vendor），离线可跑。
ES modules 不能从 file:// 直接打开，需走本地服务。

## 会动的东西

漕船放桅过桥（过桥后徐徐立桅）、橹手摇橹、船尾水痕、
舢板撑篙逆行、约 120 个行人（挑夫/伞客/凭栏看客/摊贩/船工/骆驼队）、
燕子上空盘旋、炊烟蒸汽、柳条摆动、流云漂移、华灯相萤火与灯火渐次点亮。

## 技术要点

- 自研体素管线：稀疏 Map → 面剔除 → 四角顶点 AO（曲线 0.55/0.74/0.90/1.0，
  含各向异性翻转）→ 合并 BufferGeometry；solid / glow / water 三组世界。
- 顶点色在烘焙期做 sRGB→Linear 转换（three r152+ 色彩管理），否则输出会二次提亮成粉彩。
- 真实阴影：DirectionalLight 4096 PCFSoft，normalBias 1.4（体素场景防阴影痤疮的关键）。
- 水面自定义 ShaderMaterial：深浅色带 + 流向波纹 + 星点闪光 + 手写雾 chunk。
- 时相系统：三组关键帧（颜色/光强/雾/曝光/bloom/发光强度）逐帧指数趋近插值。
- 规模：约 11 万体素 / 23 万三角形，构建 <400ms，60fps（M 系列）。

## 目录

```
index.html / style.css   界面（宣纸帷幕 + 展柜铭牌式 UI）
js/voxel.js              体素内核（Map + mesher + AO + hash）
js/build.js              场景生成（河/虹桥/船/街市/城楼/柳/远山/河亭）
js/people.js             人物系统（小人合批 + 巷道 + 船工 + 骆驼）
js/ambient.js            天空/时相/水 shader/粒子/云
js/main.js               渲染器/灯光/相机/UI/主循环
vendor/                  three r160 + OrbitControls + 后处理（本地化）
output/                  成片（final-*.png）与迭代截图（iterations/）
design.md                设计契约（必须/加分/不做）
```
