# 上河虹桥 · The Rainbow Bridge

> 清明上河图「虹桥段」的体素转译。一幅可走入的微缩木拱长卷：
> 暖阳午后，汴河穿城，漕船正过虹桥，两岸市声鼎沸。

## 立意

前作六件均为「冷色夜景 + 灯火 + 浮岛/深海」套路（浮岛×3、海×2、夜山×1），
评审反馈表明：**暖色、烟火气、第一眼之美 > 工程复杂度**（茶庭 7 分 vs 青绿 4 分）。

本作转向**白昼市井**这条无人走过的路：

- 题材锚点：清明上河图最著名的一段——无柱木拱「虹桥」+ 漕船过桥的名场面。
- 情绪基调：暖阳、人声、烟火——「人间烟火气，最抚凡人心」。
- 戏眼（叙事钩子）：一艘漕船正在放倒桅杆、缓缓穿过虹桥，桥上人群凭栏俯瞰——
  全场景的构图、机位、动效都为这一刻服务。

## 构图

一河（汴河，沿 X 流向）、一桥（虹桥横跨、对角线构图）、两岸（街市立面 + 柳），
一塔（城楼远端竖向锚点）。主英雄机位自上游斜上方凝视桥心，
美术馆展柜式构图，视线动线：柳枝 → 船 → 桥上人群 → 城楼。

## 必须（P0）

1. 自研体素管线：稀疏 Map → 面剔除 → 四角顶点 AO 烘焙 → 合并 BufferGeometry
   （solid / emissive / water 三组，沿用前作验证过的成熟管线）。
2. **真实太阳阴影**（PCFSoft 2048）——前作仅茶庭一家有，长影是午后氛围的根。
3. 三时相：**午后**（英雄相）→ 薄暮 → 华灯，统一关键帧插值，可自动巡时。
4. 戏眼动画：漕船缓缓过桥（桅杆半放、橹手摇橹、船尾水痕）。
5. 桥上与两岸行人 ~120：沿巷道行走、摆动、桥心凭栏看船。
6. 市井细节密度：摊贩遮阳伞、酒旗、蒸汽、炊烟、垂柳拂水、表木立鹤、犬、燕。
7. UnrealBloom 低强度只托灯火与水面高光；ACES 色调映射。
8. 三个电影机位（1/2/3 键 + 按钮）：虹桥全景 / 桥心俯瞰过船 / 市街漫步。
   双击回英雄机位。

## 加分（P1）

- 水面 ShaderMaterial：流动波纹 + 船行泡沫 + 暖阳高光带。
- 华灯相：窗火、桥灯、摊灯渐次点亮，星子微现，bloom 抬升。
- 柳条随风摆动（单独网格轻幅旋转）。
- 入场 3.5s 展柜推轨 + 加载帷幕。

## 不做（明确排除）

- 音频、体素编辑器、物理、多语言、移动端深度适配（reduced-motion 除外）。
- 夜景为主的默认相（英雄相必须是暖阳午后）。
- 过度 UI——控件只有：机位 ×3、时相 ×3、自动巡时。

## 验收

Playwright 真浏览器截图（三时相 × 三机位）逐张人工复核构图与配色；
控制台零报错；体素数 / 三角形数控制台自报；60fps 目标。

## 交付形态

纯静态：`index.html` + `style.css` + `js/` + `vendor/`（three r160 本地化，零远程请求，
离线可跑）。`python3 -m http.server` 或 `node .serve.cjs` 即可打开。
