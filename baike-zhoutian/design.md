# 百刻周天 · 水运仪象台

第十三件体素作品：**苏颂水运仪象台（1088，人类第一座水力天文钟塔）的实时 WebGL 转译**。
题材自选、代码全新编写（未读同级任何其他作品的代码或文档）。

## 命题

一座塔里同时有四件"真"事：

1. **真擒纵**：枢轮 36 受水勺，恒定漏壶滴入顶勺，勺满则天衡脱扣，
   轮进一格（现实 20 分钟一步，2 转/日）。每步溅水、木击有声。
2. **真传动**：齿表推导（见下），天柱 1 转/日，昼夜机轮（五层凸轮塔）随之。
3. **真报时**：五层木阁 156 次事件/日全部由凸轮产生——
   百刻摇铃（100）·时初正报牌（24）·晨钟暮鼓（2）·五更更鼓（5）·更点钲（20）。
   酉正（18:00）四层齐动，是为"酉正之礼"。十二时辰/百刻/更点换算见 `spec.js`。
4. **真天象**：浑象星球（51 星 + 银河带 + 赤道/黄道环）与星空穹顶同轴同转（1 转/日）；
   极轴倾角 34.8°（汴京纬度）；**透过望筒（窥管）正见北极星**——管半角 7.1°，极星偏 0.70°。

## 传动表（齿数为自定，恒等式由 accept-node 第 1 组守护）

| 件 | 齿 | 转速 |
|---|---|---|
| 枢轮（36 勺） | — | 2 转/日 |
| 冠轮 A（枢轮轴南端）→ 天柱轮 B | 20 → 40 | 天柱 1 转/日 |
| P2（枢轮轴北端）→ 斗链轮 W | 32 → 16 | 斗链 4 循环/日 |
| 悬臂轮 E2 → 浑象轴端 F | 36 → 36 | 浑象 1 转/日 |
| 顶轮 G2 → 三辰枢 H | 36 → 36 | 三辰/四游 1 转/日 |

水量守恒（assert）：勺出 72×24 = 斗入 96×18 = **1728 格/日**，闭循环。

## 验收（唯一可信口径）

```bash
node tools/accept-node.mjs      # 离线 45 条
node tools/serve.mjs            # :8951
python3 tools/accept-web.py     # 浏览器 31 条（连跑两轮）
python3 tools/shoot.py          # 12 张主图 → renders/ + manifest
```

秒级看几何：`node tools/raster.mjs --out /tmp/a.ppm --cam cover`
（`--night` / `--time 秒` / `--marks x,y,z;...` 出屏幕坐标与像素色），
`python3 tools/ppm2png.py` 转 PNG，`python3 tools/ascii.py a.ppm` 出字符构图。

## 诚实清单（三态标注）

- **实测为凭（probe/实跑）**：窥管见极星（浏览器拾取+像素验证）；
  剖切半径用方阵范数（欧氏半径在方环对角方位切不到墙——真踩过）；
  天柱与斗链的空间检查必须先过 pose(0) 变换（斗件建位在原点——真踩过）。
- **推导为凭（identity）**：传动恒等式、水量守恒、凸轮=事件、时辰刻换算。
- **设计取舍（impl）**：
  - 浑象/星空按 1 转/太阳日，非恒星日（差 3.9 分/日；苏颂同款取舍，不为体素刻度造 366 齿）；
  - 百刻层的可见齿 44（逻辑凸齿 100——864s/齿在 r7 体素环上加密渲染）；
  - 咬合例外：A×B、P2×W、E2×F、G2×H、天衡×勺、斗×池水（斗链过水如筒车）、
    三辰枢×子午环（极枢在环孔中——已按史实开孔）；
  - 晨昏取 6/18 定阈（凸轮可制优先于真实太阳高度）；
  - 星表为近似赤道坐标（北斗/参宿三星/织女河鼓天津形状保真，其余近似）。
