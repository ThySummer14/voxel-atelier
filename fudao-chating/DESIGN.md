# 浮岛茶庭 · 体素作品设计书

## 1. 概念与主体

**作品名**：《浮岛茶庭》（Sakura Chashitsu of the Mirage）

在虚空之上的浮岩小岛，托着一座茶寮与一株垂樱。黄昏金光斜切过飞檐，灯火初上，落樱与瀑声共坠云海。选择茶寮作参考物：它天然适合体素——屋顶曲线可阶梯化、木构可模块化、樱冠可色块堆叠，且情绪密度高（孤岛、花、灯火、水），在有限体素预算里最容易做出「可凝视的静物」而非建筑模型。

**语气**：安静、克制、博物馆展柜式凝视。不是游戏场景，是一件可缓慢环绕的微缩雕塑。

## 2. 风格 DNA

- **2D 页面**：Editorial × Cinematic——大标题衬线/黑体混排，极少 UI，深色展台，文字是旁注不是主角。
- **3D 渲染**：Voxel / 低多边形块面 + 电影感黄昏打光。块面棱角清晰，但灯光偏摄影（主光偏暖、天光偏冷、灯火自发光），避免「Minecraft 截图感」。
- **一句话锁调**：*Cinematic dusk × hand-crafted voxel diorama × museum editorial UI*。

## 4. 字体与排版

- 显示：`"Songti SC", "Noto Serif SC", "Source Han Serif SC", serif` — 作品名
- 正文/标注：`"PingFang SC", "Helvetica Neue", sans-serif` — 小字旁注
- 尺度：主标 42–56px，旁注 12–14px，字距 `0.12em` 于英文小标
- 页面几乎无容器：文字直接浮在场景边缘（不同层 + 主体关系）

## 5. 构图与布局

- 画布满屏；岛体居中偏下，上方留夜空与云。
- 岛约占画面高度 55–65%，树冠为最高点破右上三分之一。
- 相机默认 3/4 俯视 12° 左右的「展柜视角」；允许拖拽环绕、滚轮推拉。
- UI 只保留：左上作品名与副题、右下操作提示、底部细进度/视角提示线。

## 6. 场景清单（体素内容）

1. **浮岩岛**：倒锥岩层（3 层岩色）+ 苔绿顶层 + 石径
2. **茶寮**：木柱墙、障子窗（透光）、青瓦歇山顶（檐角起翘用阶梯飞檐）
3. **垂樱**：斜干、分枝、双色花冠、少量飞花粒子
4. **石灯笼**：自发光灯火 + 点光源
5. **水系**：岛缘溢水瀑（半透明体素柱 + 白沫粒子）
6. **配件**：矮竹篱、踏石、茶旗/暖帘小块
7. **大气**：环绕浮云 2–3 朵、缓慢自转的远山剪影碎片、体积感雾

## 7. 签名瞬间（记忆点）

1. **首屏 3 秒**：金光切过飞檐与花冠，灯火与天光冷暖对撞
2. **落樱**：花瓣粒子以不同转速下坠，偶尔擦过镜头
3. **云下瀑**：岛底碎岩间坠下一缕水帘，末端化成白沫消失
4. **环绕揭示**：拖动到侧逆光角度时，屋脊剪影 + 树冠透光

## 8. 交互

| 触发 | 视觉变化 |
| --- | --- |
| 静置 | 相机极慢自动环绕 + 树冠/云/花瓣持续微动 |
| 拖拽 | 自由环绕岛体 |
| 滚轮 | 推近/拉远（限制距离，避免穿模） |
| 悬停画布 | 提示微淡出；自定义光标细环 |
| 双击 | 回到默认展柜视角（缓动） |

## 9. 技术栈

- three.js r160（本地 vendor，离线可跑）
- `InstancedMesh` 合批体素（单 draw call 大块）
- 每实例颜色 + 顶面微提亮伪 AO
- `MeshStandardMaterial` + 方向光/半球光/点光源（灯火）
- 粒子：花瓣与瀑沫用 InstancedMesh 小片
- 无构建步骤：`index.html` + `main.js` + `vendor/`

## 10. 优先级

**必须**：完整浮岛+茶寮+垂樱+灯笼+灯火光；落樱；环绕交互；黄昏主视觉；无报错可打开。

**加分**：瀑布粒子、云、双击回位、自定义光标、檐角起翘的阶梯飞檐、障子透光。

**不做**：滚动叙事长页、音效、多人、编辑器。
