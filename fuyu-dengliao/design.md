# 《浮屿灯寮》— 体素浮岛作品 · 设计说明

## 1. 概念与题材

**载体**：一座悬浮于暮色中的体素山岛。山腰有茶寮，崖边飞瀑落入云海，石灯笼与窗火次第点亮。

**语气**：静谧、温润、微奇幻。不是 Minecraft 的方块游戏感，而是**手工微缩模型**——每一粒方块都像被黄昏灯打得住。

**一句话风格**：`Cinematic Voxel Diorama × Editorial 中文排版 × 暮色冷暖对撞`  
（电影感微缩体素 × 杂志式大标题 × 靛蓝天空对琥珀灯火）

## 2. 风格锚点

| 轴 | 锚点 | 借什么 |
|---|---|---|
| 2D 界面 | 电影字幕卡 / 独立杂志内页 | 大字距中文标题、极简章节点、大量留白 |
| 3D 渲染 | 手工微缩场景 + 舞台光 | 体素面剔除 + 顶点 AO、点光源暖色、雾、Bloom 只打在灯火 |
| 参考物 | 《纪念碑谷》体块剪影 × 吉卜力黄昏小镇 × 博物馆建筑模型 | 剪影清晰、冷暖对比、可慢慢绕看 |

**明确排斥**：像素噪点滤镜、赛博霓虹、UI 堆满按钮、自动旋转的廉价展示台。

## 5. 版式与节奏

- 全屏 WebGL 画布为唯一舞台；DOM 文字浮在上层（不同层关系，保证可读）。
- 左上：作品名；右：四章节指示点；底部：滚动提示。
- 间距节奏 8px 基数；文字块最大宽约 28em，靠左或靠右三分之一，不挡主体。
- 每屏信息密度低：一个标题 + 两行诗性文案，其余交给画面。

## 6. 分镜清单

| # | 章节 | 类型 | 唯一论点 | 镜头 |
|---|---|---|---|---|
| 0 | 浮屿 | Hero 全景 | 这是一座悬在暮色里的可居小山 | 远景微俯，缓慢轨道 |
| 1 | 茶寮 | 近景建筑 | 木作与窗火是岛的心跳 | 侧近景，茶寮为视觉中心 |
| 2 | 飞瀑 | 中景动态 | 水把静山剪开一条银线 | 对准崖缘瀑布，略仰 |
| 3 | 掌灯 | 近景氛围 | 夜色加深，灯火与萤光接管画面 | 低角度绕灯，Bloom 增强 |

## 7. 交互

| 触发 | 视觉变化 |
|---|---|
| 鼠标拖动 | 环绕轨道（限制俯仰，不穿模） |
| 滚动 / 章节点击 | 相机沿路径缓动到下一章，文案交叉淡入 |
| 空闲 4s | 极慢自动环绕 |
| 鼠标移动 | 轻微视差（相机目标偏移） |
| 点击灯笼 | 该灯短暂增亮脉冲 |
| 常驻动画 | 瀑布流动、水面闪、树叶微摆、萤火虫漂移、花瓣缓落 |

## 8. 技术

- **Three.js r160**（本地 vendored，离线可跑）
- **体素系统**：`Map(x,y,z)→color`，面剔除 + 四角 AO，合并为单 `BufferGeometry`（可合并材质分组）
- **发光体素**：灯笼/窗单独材质 `MeshStandardMaterial` emissive + 点光源
- **后处理**：`EffectComposer + UnrealBloomPass`（低强度，只让灯火「活」）
- **相机**：四段关键帧路径 + 平滑插值；OrbitControls 可接管
- **无构建步骤**：原生 ES modules

## 9. 优先级

**必须**
1. 完整体素浮岛（倒悬岩基 + 山体 + 茶寮 + 树 + 桥 + 瀑 + 潭）
2. 顶点 AO + 冷暖灯 + 雾 + Bloom
3. 四章镜头叙事 + 文案
4. 拖动环绕 + 滚动章节 + 空闲自转

**加分**
5. 萤火虫 / 花瓣 / 瀑布动画
6. 灯笼点击脉冲
7. 入场淡入与标题浮现

**不做**
- 音频、多语言切换、移动端复杂手势以外的定制
