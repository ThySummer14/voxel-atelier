# 《鲸落邮局》设计提案

## 一句话概念

在海拔 −1093 米的无名海沟，一座邮局借巨鲸的胸骨建成；最后一个邮差沿着鲸骨路，把来不及抵达的信送进深海。

## 作品定位

- 类型：可交互体素装置艺术 / 单页 WebGL 体验
- 观众：第一眼是宏大的鲸骨建筑，第二眼发现温暖邮局与忙碌邮差，近距离才看到藏在珊瑚、贝壳和水母中的微小生命
- 情绪曲线：静谧敬畏 → 发现温暖 → 轻触叙事 → 离开时仍记得一束海沟中的灯
- 核心意象：**死亡不是终点，海底仍有人替记忆点灯。**

## 场景构图

作品采用“前景贝壳—中景邮局—远景鲸骨”的三层构图：

1. 前景：失语水母、发光海葵、邮差、邮筒和木质码头，形成尺度参照。
2. 中景：嵌在鲸肋中的暖色邮局，是画面唯一高饱和橙红光源。
3. 远景：完整但残破的巨鲸骨架在蓝绿色雾中消失，强调“鲸落”与时间感。

画面以冷青色包围暖橙色，邮局灯邮一盏亮起时，叙事比单纯技术展示更强。

## 五个观看层次

- **第一层：巨物**——完整鲸骨轮廓与胸腔建筑。
- **第二层：秩序**——骨桥、木栈道、灯笼和码头形成可读路径。
- **第三层：生活**——窗台盆栽、热汤、晾晒的信封、邮差的投递动作。
- **第四层：生态**——黑烟囱、管虫、珊瑚、水母、远景鱼群与海雪。
- **第五层：秘密**——可点击邮筒会得到一段短笺；不同状态有不同环境声与光线。

## 交互

- 鼠标拖拽环视、滚轮缩放、右键平移；首次进入自动播放缓慢镜头。
- 数字键 `1`–`4` 切换电影机位：全景、骨门、邮筒、鲸尾。
- `L` 切换提灯；提灯会照亮附近体素并吸引发光鱼群。
- 点击发光邮筒投递信件，邮差移动、邮筒亮起、字条在界面中展开。
- 底部潮汐控制器切换“静潮 / 鲸歌 / 黑潮”，改变水流、浮游粒子、鱼群、雾和声景。
- `C` 自动巡游，`H` 隐藏界面，`R` 回到初始机位。
- 音频默认关闭，首次点击后由 Web Audio 实时合成，不依赖外部音频文件。

## 视觉语言

- 所有可见实体均由立方体、方柱或方片组成，不使用光滑球体作为主要造型。
- 体素不做过度统一的尺寸：结构 0.5–1.0，生态 0.08–0.25，浮游粒子 0.025–0.08。
- 色彩以深蓝、松石、贝壳白、珊瑚橙为骨架；少量荧光黄绿作为“活着”的信号。
- 灯光包含：冷色顶光、邮局暖光、生物荧光、邮筒脉冲光、远处无来源的幽蓝轮廓光。
- 体积感来自分层雾、远景负空间、前景遮挡和缓慢视差，不依赖沉重后处理。

## 技术实现

- Three.js + WebGL2，原生 ES Modules。
- 同材质体素合并为 `InstancedMesh`，控制 draw call；发光体单独使用不受色调映射影响的实例层。
- 程序化生成鲸骨、肋骨、脊椎、海底地形、珊瑚、海雪、灯笼和所有建筑细节，无图片资源依赖。
- 轻量 Bloom 仅服务于灯笼、生物荧光和海面光束；保留颗粒、渐晕和色偏等胶片式 CSS 叠层。
- 自适应 DPR 和实例密度；窄屏减少粒子、降低 DPR、调整机位和 UI。
- 支持 `prefers-reduced-motion`，低动态模式关闭自动漂移、镜头呼吸和大部分循环动画。
- Web Audio 只在用户手势后启动，包含低频海压、鲸鸣、邮筒钟声、投递提示和机械舱门声。

## 验收标准

- 首屏无白屏、无控制台错误，主场景在 3 秒内出现。
- 默认机位能清楚读出“鲸肋 + 邮局 + 海沟”三层叙事。
- 4 个电影机位均无穿模、裁切失衡和主体遮挡。
- 4 种潮汐状态有明确但克制的视觉差异。
- 所有按钮可用、键盘快捷键有效、界面可隐藏、音效可关闭。
- 1440×900 与 390×844 均无溢出或遮挡；触控拖拽可用。
- 浏览器自动化完成真实点击、拖拽、快捷键和截图巡检。
