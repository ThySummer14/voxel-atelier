# 《鲸落邮局》交付报告

## 交付物

作品目录：[鲸落邮局](/Users/thysummer/工作流/code/体素/jingluo-youju)

- `index.html`：作品入口、首屏、交互面板、无障碍文案
- `style.css`：深海色彩、玻璃 HUD、响应式布局、胶片颗粒与暗角
- `main.js`：Three.js 场景、体素构建、镜头、海况、声景、投递逻辑

```bash
cd "/Users/thysummer/工作流/code/体素/jingluo-youju"
node .serve.cjs
```

然后打开 [http://127.0.0.1:4173](http://127.0.0.1:4173)。

## 已实现

- 2679 个可见体素构件：巨鲸脊柱、肋骨、头骨、邮局、码头、邮筒、邮差、珊瑚、黑烟囱、船骸、远景鱼群与海雪。
- 4 个电影机位：全景、骨门、邮筒、鲸尾；支持数字键 `1`–`4`。
- 3 种海况：静潮、鲸歌、黑潮；联动雾、光照、Bloom 阈值、浮游速度、鱼群和 Web Audio 声景。
- 投递循环：点击发光邮筒 → 邮差移动 → 邮筒发光 → 纸张短笺出现 → 邮件内容轮换。
- 交互：自动巡游 `C`、提灯 `L`、环境声 `M`、净屏 `H`、回位 `R`、作品说明 `?`。
- 音频：Web Audio 实时合成海压低鸣、鲸鸣、邮筒钟声，不依赖外部音频文件。
- 响应式：390×844 手机布局已适配；相机画布通过 `ResizeObserver` 跟随容器。
- 兼容性：WebGL 画布尺寸回退、内嵌 WebView 的零尺寸保护、后处理性能自适应回退。

## 设计取向

这件作品刻意避开同目录既有作品常见的“深蓝夜景 + 单一暖灯 + 展柜环视”套路：它用冷色海沟包裹暖色邮局，用“鲸落”承载记忆与告别的叙事，用投递行为和三段信件把体素静物变成一件有过程的作品。
