# 云海织星 · The Astral Loom

> 以月为梭，以风为线。云海之上，织者将人间未竟的愿望捻成光，一针一针，织入夜空。

一件从零生成的原创体素世界：云海之上的织星所，由巨型天机织轮、星穹之门、灯阁、崖居与朝圣山径组成。所有几何、纹理、粒子与声音均由代码实时生成，没有使用任何外部图片或现成场景素材。

## 观看

- **直接观看（推荐）**：打开 `dist/云海织星.html`。这是单文件版本，离线可用，双击即可。
- **开发版**：在项目目录运行 `python3 -m http.server 8123`，打开 `http://127.0.0.1:8123/`。
- **高清海报**：`poster/` 目录内提供带题签版与无题签版 4K 海报，以及织机、灯阁细部图。

## 操作

| 操作 | 效果 |
| --- | --- |
| 拖动 | 环视整座云上工坊 |
| 滚轮 / 双指 | 远近 |
| `01 云海` / `02 织机` / `03 灯阁` | 三个电影机位 |
| `E` 或点击「引」 | 引一缕星线，唤醒织轮 |
| 右下声符 | 开启 / 关闭环境声音 |
| `R` | 回到云海全景 |

场景会自动从远景推入，并在长时间静置后极慢地环绕。手机与桌面均有独立构图。

## 工艺

- **体素世界**：以自定义体素体积与表面网格生成器搭建，约 87 万个实心体素，逐面剔除内部面、烘焙逐面 AO 与材质色差，保留像素边缘。
- **场景**：程序化山峰、悬崖、苔径、瀑布与浮石；手写参数的中式灯阁、双塔、织轮、星种、灯笼串、小人与牌楼式檐角。
- **天穹**：自定义天球渐变、近千颗带十字光芒的恒星、柔光星云、体素月面、云海体积雾与远岸云雾。
- **织天机**：可旋转的黄铜织轮、43 根摆动经线、穿行的金梭与实时绘制的纬线、星图织门、悬浮星种与环轨。
- **光色**：月光主光 + 正面冷补光 + 灯笼暖光 + 星种青光；UnrealBloom、ACES 色调映射、暗部青调与高光暖调、暗角与细颗粒。
- **声音**：Web Audio 生成的 55Hz 呼吸低鸣、风床、五声音阶星铃；点击「引」会生成一段短琶音。
- **性能**：桌面 2× 像素比上限，移动端自动降至 1.5×、2× MSAA、1024 阴影贴图与更低 bloom；隐藏页面时暂停更新。
