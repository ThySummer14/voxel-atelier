# 《机心》— 作品契约

## Goal
做一件我认为是"十分完美"的实时体素作品：**一枚镂空陀飞轮腕表**，它不是模型摆拍，而是**真的在走时**——
指针读的是打开页面那一刻的本地时间，陀飞轮笼框 60 秒整一圈即秒针，摆轮 2.5 Hz 真实摆动，
擒纵轮每一拍跳一齿。题材全新：本工作区前作皆山水/楼阁/岛礁，本作是**微缩机械静物**。

## Context
- 工作区 `/Users/thysummer/工作流/code/体素/jixin`，非 ASCII 路径，验收脚本必须按真实路径跑。
- **硬约束（用户原话）：禁止参考其他作品。** 本件从调色板、雕刻器、着色模型到交互全部新写，
  不读取、不复制同级其余八件目录的任何代码或设计文档。
- 技术底座：three.js 0.160（已 vendor 到 `vendor/three.module.js`，离线可跑，不依赖 CDN）。

## Done When（每条都要真跑并出示证据）
1. **走时正确性**：`JX.probe()` 连续两次间隔 ≥5 s 采样，笼框角度增量 ÷ 真实时间增量 = 2π/60 (±1%)；
   时针/分针角度反解出的时刻与 `Date` 差 < 2 s。断言的期望值来自 `Date.now()`，不来自被测代码常量。
2. **节拍真实性**：5 秒内擒纵跳齿数 = 10±1（2.5 Hz），且擒纵轮每 15 跳转一圈；拔出表冠（hack）后跳齿数**冻结为 0**。
3. **几何可读性**：`tools/raster.mjs` 出图后我逐张 Read 判定——齿纹表圈、鱼鳞纹、红宝石、蓝钢螺丝、
   游丝螺旋、12/3/6/9 字钉、指针在 720px 缩略下**一眼可辨**；不可辨即视为未完成。
4. **性能**：playwright headless（`--use-angle=metal`）1600×1000 下 fps ≥ 55，且三角数 < 60 万。
5. **上链闭环**：拖动表冠 N 格 → 动力储存数值上升、摆幅增大、棘轮点击计数增加，三者同帧变化（不是只动 UI）。
6. **视觉验收**：`tools/shoot-all.py` 一次出 ≥10 张（含标准机位/微距/夜光/拆解/停秒/放大镜），
   每张必须被我看懂并写进报告的"这张看到什么"。
7. 控制台零 error；`npm run accept` 退出码 0（不用管道后的退出码下结论）。

## Boundaries
- 不做商用授权相关顾虑（纯自用评鉴）。不改动同级其他作品目录。
- 不引入构建工具链/打包器：纯 ESM + 静态服务。
- 不为了"看起来高级"堆后处理管线（Composer/bloom/SSAO）；光照**烘焙进顶点色**，
  与 Node 预览器共用同一套 Lambert+AO 常数，保证"离线看到什么 = 浏览器渲染什么"。
- 声音只在用户手势后启动；静音不能影响任何视觉状态。

- `交付报告.md`（已验到哪一层 / 未验清单 / 缺陷修复轮次）
