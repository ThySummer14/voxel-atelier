### 0.1 从照片读出的关键事实（决定建模策略）

1. **尾屏不是实心圆盘。** 开屏时数百枚延长的尾上覆羽呈放射状撑开，羽轴细而裸、羽枝稀疏，背景可透过羽屏看到。实心盘会失真。
   → 建模为：辐射细羽轴 + 稀疏羽枝 + 近尖端的金黄"羽片" + 末端眼斑；基部另有一团金绿鳞状"披肩"。
2. **眼斑成同心弧（多行）排列**，外行最大、位于屏缘，向内逐行缩小、半径递减。
   → 4–5 行眼斑，半径递减、每行数量递减、交错排布。
3. **眼斑环带结构**（由内向外）：靛蓝近黑的"心形/肾形"核（中央带一条青蓝竖纹）→ 翠绿环 → 青绿细边 → 金黄/橄榄金"场" → 铜褐缘 → 散开的铜粉色裸羽枝。
4. **身体相对尾屏很小**：颈胸虹彩钴蓝，背/肩金绿鳞状，折叠翼黑白虫蠹斑 + turquoise 鳞带，脸有白斑，冠羽为细裸轴顶蓝绿小扇瓣，喙象牙灰微下弯，腿灰粉。
5. **虹彩是结构色**：随视角在 蓝↔绿↔金 之间流转。→ 渲染用视角相关薄膜虹彩近似。

## 1. 坐标与分辨率

- 轴：X 左右（屏宽），Y 向上（地面 Y=0），Z 深度（+Z 朝观者）。
- 体素边长 ≈ 0.5 cm。网格 `NX×NY×NZ = 420×270×220`，X∈[-210,210)，Y∈[0,270)，Z∈[-110,110)。
- 尾屏枢轴（尾基）≈ (0, 60, +10)；屏半径 R≈190；屏顶 Y≈250；屏宽 ≈ ±190。
- 身体：足 Y0 → 头顶 Y≈130 → 冠羽 Y≈150；身体前置于 Z≈+40。
- 尾屏平面近 XY，向 -Z 微凸（凸面朝观者），边缘后掠。

## 3. 调色板（材质分区）

虹彩材质（mat=1，视角流转）：颈胸钴蓝、肩 turquoise、眼斑翠绿/青绿、冠瓣蓝绿。
金属材质（mat=2，金/铜高光）：眼斑金黄场、铜褐缘、披肩金绿、羽轴铜粉。
哑光材质（mat=0）：黑白翼斑、脸白、喙、腿、底座苔石草花。

眼斑环带色（内→外）：
`#0a1430` 核 → `#123a6b` 核缘青蓝 → `#0e9e57` 翠绿 → `#35e0c0` 青绿边 → `#c9a227` 金黄场 → `#b06a2a` 铜褐缘 → `#b07860` 裸羽枝。

## 4. 渲染与交互（three.js，本地 vendored）

- InstancedMesh + 每实例属性：baseColor、AO（烘焙）、mat（虹彩/金属/哑光）、seed。
- MeshStandardMaterial + onBeforeCompile 注入：视角相关虹彩（fresnel 驱动色相流转）、AO、眼斑微自发光。
- 光照：半球光 + 暖主光(投影) + 冷补光 + 轮廓光；PMREM 环境；渐变暮色天幕；雾。
- 后处理：UnrealBloom 低强度，点亮眼斑与虹彩高光。
- 动画：羽屏微摆/呼吸、虹彩随时间流转、落英飘落、冠羽轻颤；自动转台可开关。
- 交互：OrbitControls 拖拽/滚轮；点击眼斑聚焦；视角预设（正面/侧/特写/俯）；重置。
- 导出：MagicaVoxel `.vox`；Minecraft `.litematic`/`.schem`（颜色→混凝土/羊毛/陶瓦）。

## 5. 迭代记录

每轮"渲染 → 亲眼观察 → 修正"。软件预览（`render.py`）用于快速形状迭代，WebGL 截图（`shot.py`/`cover.py`，playwright + `--use-angle=metal`）用于光照/材质迭代。

- **R1（软件预览）**：初版尾屏偏实心、身体过圆、冠羽成"竖直白柱+蓝横帽"、披肩是干净半圆盘。→ 确立透空蕾丝策略；冠羽改放射细轴+小扇瓣。
- **R2**：尾屏几乎为平面板、缺真实开屏凸面后掠。→ 加 Z 向曲率（边缘后掠至 −65）、行分层、填充羽加密；披肩改贴背 3D 鳞状丘；颈/头/翼细化。
- **R3（首次 lit）**：背景下半亮橙如沙漠；眼斑金晕过大过黄像"煎蛋"；羽屏偏"串珠网"；身体蓝过饱和偏卡通；光照太亮太塑料。→ 加真实地面+暮色天幕；眼斑环带重平衡（核加大、金晕收窄改橄榄/铜）；羽枝改人字纹平行strand；体色加深；收敛光照。
- **R4**：草丘被染"薄荷绿"（哑光体素也带 metalness 环境反射）；虹彩出现品红偏色；地平线硬边。→ 按材质分区 roughness/metalness（哑光全粗糙）；虹彩限定 蓝↔绿↔金 三-stop（无品红）；雾色匹配地平线暖带。
- **R5**：颈基"白领"为朝上胸肩面高光溢出。→ 虹彩材质粗糙度 0.34→0.52、胸部色带对比减弱；正面机位收紧使尾屏撑满；产出干净静帧与封面；导出 .vox/.schem 并读回校验。

## 6. 渲染/材质实现要点

- `InstancedMesh` ×3 组（身体+地面 / 尾屏 / 冠羽），每实例属性 `aAO/aMat/aSeed/aEmis`；尾屏与冠羽绕各自枢轴微摆。
- `MeshStandardMaterial.onBeforeCompile` 注入：AO 乘算；fresnel 驱动虹彩（mat1 三-stop 蓝绿金、mat2 金sheen）；眼斑微自发光；按 mat 分区 roughness/metalness。
- 光照：半球 + 暖主光(2048 阴影) + 冷补 + 轮廓；PMREM RoomEnvironment（envMapIntensity 0.3）；渐变暮色天幕 + FogExp2；UnrealBloom 低强度。
- 落英为独立 InstancedMesh 粒子（飘落+摆动+自旋），可开关；`prefers-reduced-motion` 自动关闭环游/落英/微摆。
