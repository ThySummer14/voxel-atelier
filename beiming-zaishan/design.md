# 《北冥载山》· 体素巨作设计书

## 1. 概念与主体

**作品名**：《北冥载山》
**副题**：The Kun Bears the Mountain
**形态定稿**：巨鲲（叉尾鱼形）背负仙山与三重檐楼阁——以《逍遥游》「北冥有鱼」为骨，圆润叉尾、弓背、发光目构成可读剪影。

**参考物**：庄子《逍遥游》「北冥有鱼，其名为鲲。鲲之大，不知其几千里也。」——取「巨鲲负山」这一意象作雕塑主体：一头以体素雕刻的星海巨鲲，背负一座仙山与重檐楼阁，驮着人间灯火，缓缓航过北冥星渊。

**为何是它**：既有文学骨相，又天然适合体素——鲸体可参数化切面，山岩可层叠，飞檐可阶梯起翘，灯火可自发光成「万灯」签名。与工作区既有的两件浮岛茶寮完全区隔，尺度更大、剪影更独特、神话密度更高。

**语气**：浩瀚、庄严、缓慢。不是游戏关卡，是一件可环绕凝视的**博物馆级微缩神话雕塑**。

**一句话锁调**：*Cosmic night × hand-carved Kun leviathan × mountain-temple diorama × ten-thousand lantern bloom*

## 2. 风格 DNA

| 轴 | 锚点 | 借什么 |
|---|---|---|
| 2D 页面 | 星图边注 / 古籍笺注 / 美术馆展签 | 极窄字距中文标题、章节数字、大量深空留白 |
| 3D 渲染 | 手工体素微缩 + 舞台夜光 | 面剔除 + 顶点 AO、冷月主光、灯火自发光、Bloom 只托灯火与星瀑 |

**明确排斥**：Minecraft 截图感、赛博霓虹、UI 按钮堆砌、廉价转台自动旋转。

## 4. 字体与排版

- 显示：`"Songti SC", "Noto Serif SC", "Source Han Serif SC", serif` — 作品名「北冥载山」
- 正文/标注：`"PingFang SC", "Helvetica Neue", sans-serif`
- 拉丁点缀：`"Times New Roman", serif` 小号大写宽字距
- 主标 56–72px / 字距 0.22em；章节 28–36px；旁注 12–14px / 行高 1.85
- UI 浮层（不同层），不进 3D 光照，保证可读

## 5. 构图

- 鲲体横贯画面，头右尾左（默认机位）；山与楼阁压在鲲背中前段，最高点破上三分之一。
- 鲲 + 山约占画面高度 60–70%，上方留星渊与月。
- 默认机位：侧前方 3/4，略俯 8–12°，FOV 32–38。
- 允许拖拽环绕、滚轮推拉（限距限俯仰，不穿模）。

## 6. 场景清单

1. **巨鲲**：参数化椭球切面躯体、尾鳍双叶、胸鳍、背脊、口线、发光目、腹褶、生物荧光斑
2. **背负仙山**：层叠岩体、主峰、侧峰、苔皮、薄雪
3. **重檐楼阁**：三重檐楼阁式塔 + 侧亭 + 连廊 + 石阶 + 台基
4. **松**：3–5 株墨松，扭曲斜干
5. **星瀑**：山缘 2–3 股瀑布坠入虚空，末端化沫
6. **灯火**：檐下灯笼、窗火、路径石灯（自发光 + 少量点光）
7. **大气**：星场、月轮、星云、环鲲云、落光尘、瀑沫粒子

## 7. 签名瞬间

1. **首屏 3 秒**：侧光切开鲲背剪影，楼阁灯火从山中亮起
2. **万灯**：章内灯火次第点亮，Bloom 托出琥珀光晕
3. **星瀑坠渊**：水帘从山崖坠入星海，沫粒向上飘散
4. **目之荧光**：鲲目与身侧荧光斑随镜头角度微闪
5. **侧逆光揭示**：绕到背光侧，屋脊金饰与鲲缘冷光勾边

## 9. 技术栈

- three.js（本地 vendor，离线可跑）+ EffectComposer + UnrealBloomPass + OutputPass
- 体素：`Map` 场 + 面剔除 + 四角顶点 AO + 色抖动，solid / emissive / water 分组合并
- 灯光：半球冷天光 + 月方向光 + 暖点光（灯火）
- 粒子：星尘 / 瀑沫 / 流萤
- 无构建步骤：原生 ES modules

## 10. 优先级

**必须**：完整巨鲲 + 背山楼阁 + 松 + 星瀑 + 灯火；AO+Bloom；四章叙事；环绕交互；可离线打开无报错。

**加分**：生物荧光、点击脉冲、双击回位、自定义光标、飞檐起翘、入场显形。

**不做**：音效、移动端复杂手势、编辑器、多语言。
