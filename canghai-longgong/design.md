# 沧海龙宫 · Palace of the Dragon King

> 暮霭沉沉，一座东方龙宫浮升于深海之上。
> 琉璃飞檐、珊瑚宝柱、龙脊蜿蜒——万顷波涛中，一灯如豆。

## 立意

工作区十余件作品覆盖了浮岛（×3）、古镇市井（×2）、鲸负仙山、风信鸡、
盐田、晒秋——**唯独无人动过「海」这张牌**。

本作以「龙宫」为题——

- **题材锚点**：中国神话中龙王的水下宫殿，化用敦煌「海龙王赴会」壁画意象。
- **情绪基调**：沉静、深邃、瑰丽——暮色大海中的幽微光芒。
- **戏眼**：一条体素神龙从海面一侧腾跃升空，龙身半入云海半在水下，
  连接天与海的两个世界。
- **差异化**：
  1. 唯一的「海洋 + 暖暮」组合（前作海系均为深夜冷调）
  2. 多层叠构：海底珊瑚礁 → 水面 → 龙宫建筑群 → 天空
  3. 神龙动态：大型生物体素雕塑 + 蜿蜒飞行动画

## 构图

中央矩形基座（海底珊瑚礁岩），上方耸立三重檐龙宫主殿。
左右各有阙楼、廊桥相连。前方牌坊门楼。
神龙从右侧海面腾起，蜿蜒环绕宫殿上空。
水面以透明 shader 呈现，水下可隐约透见珊瑚与基座。

英雄机位：正面偏右上方 45°俯瞰，兼顾龙宫全貌与神龙身姿。

## 技术

- Three.js r160（本地 vendored）
- 体素内核：稀疏 Map → 面剔除 → 四角 AO → 合并 BufferGeometry（solid / glow / water 三组）
- 水面 ShaderMaterial（透明波纹 + 海面高光）
- 天空穹顶 ShaderMaterial（暮色渐变）
- UnrealBloom 后处理（低强度，只托宫灯与龙鳞高光）
- ACES 色调映射
- PCFSoft 阴影
- 三个电影机位 + 自制轨道控制

## 必须（P0）

1. 完整龙宫建筑群（主殿三重檐 + 阙楼 + 廊桥 + 牌坊）
2. 海底珊瑚礁基座（多色珊瑚 + 海草）
3. 体素神龙（蜿蜒身躯 + 龙须 + 鳞片色带）
4. 水面 shader（透明 + 波纹 + 倒影暗示）
5. 暮色天穹 + 远山剪影
6. 宫灯自发光 + Bloom
7. 真实阴影 + 顶点 AO
8. 三机位 + 轨道环视

## 加分（P1）

- 神龙蜿蜒飞行动画
- 气泡粒子（海面升起）
- 流云
- 入场推轨
- 鱼群粒子

## 不做

- 音频、编辑器、多语言、移动端深度适配
