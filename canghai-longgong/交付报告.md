# 「沧海龙宫」作品交付报告

## 作品概述

**主题**：中国神话中龙王的海底宫殿，暮色深海中浮升的东方幻境。

**立意差异化**：在工作区 16 件体素作品中，这是**唯一的海洋题材**。
前作覆盖了浮岛、古镇、鲲鹏、风信鸡、盐田、晒秋——无一件触碰「深海龙宫」这个
中国神话中最具想象力的空间意象。

## 核心亮点

### 1. 三重檐龙宫建筑群
- 主殿三层递收的庑殿式屋顶，琉璃碧瓦金脊
- 左右阙楼 + 朱红廊桥对称连接
- 前方三开间牌坊门楼
- 白玉台基 + 翡翠栏杆

### 2. 体素神龙
- 沿三维参数螺旋曲线生成蜿蜒龙身
- 正交截面系统（计算切线→法线→副法线，保证每段截面正确朝向）
- 龙背深青 + 龙腹金色的双色鳞带
- 龙脊刺、龙爪（四对）、龙鬃、分叉鹿角、龙须、龙珠

### 3. 海底珊瑚世界
- 五种色系珊瑚（红/橙/粉/紫/黄）× 三种形态（柱状/扇形/团状）
- 海草丛（随机倾斜模拟水流）
- 海底生物（海星、贝壳、珍珠、海龟）
- 定海神针式发光珍珠柱

### 4. 氛围系统
- 暮色天穹 ShaderMaterial（落日晚霞光晕）
- 海面透明 ShaderMaterial（波浪起伏 + 流光 + 散点高光）
- 星空粒子层
- 气泡粒子（从海底上升）
- 鱼群粒子（环游巡弋）
- 体素流云
- 宫灯光晕呼吸动画

### 5. 技术管线
- 自研体素内核：bit-packed key → 面剔除 → 四角顶点 AO → 合并 BufferGeometry
- 面朝向着色（竖直面 0.93、顶面 1.0、底面 0.66、前后面 0.86）
- solid / glow 双世界分组渲染
- PCFSoft 4096×4096 阴影贴图
- ACES 色调映射
- 自制轨道相机 + 三电影机位 + 入场推轨

## 运行方式

```bash
cd 沧海龙宫
node .serve.cjs
# 访问 http://localhost:8765
```

或：

```bash
python3 -m http.server 8765
```

## 交互

- **拖拽**：环绕轨道浏览
- **滚轮**：推拉缩放
- **双击**：回到全景 + 重启自动旋转
- **底部按钮**：全景 / 龙宫 / 龙首三个电影机位
- **空闲**：自动缓慢环绕
