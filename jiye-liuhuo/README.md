# 《极夜流火》 (Flowing Fire in the Polar Night)

> 1928 太平洋型 4-6-2 极地干线客运蒸汽机车 · 全工程剖切与华氏配气动力学  
> 实时 WebGL 体素作品 · 2,982,637 三角面 · 60 FPS · 纯程序化几何与声学

---

## 快速游览

在终端中进入本目录并启动本地服务：

```bash
cd 极夜流火
node tools/serve.cjs
```

然后在现代浏览器（推荐 Chrome / Safari / Edge）中访问：
👉 **http://127.0.0.1:8961/**

---

## 交互操纵说明

- **鼠标拖拽**：360° 环视全景
- **鼠标滚轮**：缩放视距
- **空格键 (Space)**：按住拉响客运五和弦经典汽笛（A大调五和弦，纯 Web Audio 合成）
- **按键 X**：一键切换【万钧机心 · 锅炉纵向工程剖切】，查看 84 根内部火管与千度烈火
- **按键 1 ~ 6**：快速切换预设导播镜头：
  - `[1]` 铁流破晓 · 全景
  - `[2]` 华氏配气 · 微距
  - `[3]` 万钧机心 · 剖切
  - `[4]` 司炉罗盘 · 驾驶室
  - `[5]` 破雪先锋 · 探照灯
  - `[6]` 极光巡礼 · 苍穹
- **按键 M**：静音 / 开启音效
- **底部司炉操作台**：
  - **节流阀滑块 (Speed)**：0 ~ 120 km/h，实时驱动动轮角速度与四拍排汽频率
  - **换向切断手柄 (Cutoff)**：-75% 到 +75%，实时改变膨胀导管中滑块高度与气门行程

## 自动化复验

### 1. 离线数学与几何真值检验
```bash
node tools/accept-node.mjs
```
检验 36 色调色板、30-bit 紧凑位图编解码、华氏配气解析恒等式、曲柄半径守恒、连杆长度守恒与双缸 90° 正交锁死（20/20 项断言全部真跑）。

### 2. 真机浏览器无头运行验收
```bash
python3 tools/accept-web.py
```
使用 Playwright 在 1600×1000 视口下启动 Chromium，自动核验控制台零错误、WebGL 画布正常渲染、遥测数据闭环与机位切换稳定性。

### 3. 生成 12 张高清实景摄影
```bash
python3 tools/shoot.py
```
自动巡航各机位与工况，输出 12 张高清原图至 `renders/` 目录。
