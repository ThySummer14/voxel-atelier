# 候风 · 设计文档

体素第十一件。张衡候风地动仪（132 AD）的实时 WebGL 转译。
签名交互「候震」：**都柱倾 → 八道发 → 龙吐丸 → 蟾衔丸 → 金声**——全因果链可见。

## 为什么是地动仪

- 八龙衔丸、八蟾承之，轮廓在体素语言里极醒目（八方对称 + 两层环形角色）。
- 它是中国古代科技史上唯一"会真的报告地震"的仪器：丸落即方向，金声即警报。
  签名交互因此是**机制本身**，不是装饰动画。
- 与前作（山水/楼阁/岛礁/陀飞轮）彻底错开。

## 结构（全部参数在 `js/spec.js` 的 `L`）

| 件 | 体素实现 |
|---|---|
| 尊体 | 青铜壳（r15，y3–22），乳钉纹 24×2，下段铜绿淤积 |
| 剖面 | 东向 52° 开窗（y6–19），门柱 + 上下横梁；内部机构一览无余 |
| 都柱 | 中央柱（r3，y4–20），底部枢轴，震时向震中方向倾 ≤4.5° |
| 八道 | 8 根辐条杠杆（y10）+ 金尖触发销，震时下沉 3.4° |
| 八龙 | 颅/吻/双角/金眉/龙须/立鬃/琥珀目，口含铜丸（露半） |
| 八蟾 | 伏于底座沿，张口承丸，疣粒 + 凸目 |
| 悬灯 | 套在都柱上的灯环（y13–14）——尊内长明灯，照亮八道（剖面可见） |
| 火盆 | 8 座错开 22.5°，火光闪烁（bake 暖光 + 精灵光晕） |
| 浮岩 | 直径 52 的浮岛 + 3 块浮石碎块（轻浮动） |

## 渲染管线（离线 = 在线）

- `js/bake.js`：半球光 + 主光（暖）+ 补光（冷）+ 26 邻 AO + **火盆距离衰减暖光**
  （含尊内悬灯）→ 逐面 RGB。Node 光栅与 three.js 共用同一组常数与同一份输出。
- `js/main.js` `mergePart()`：六向贪心合并，23.4k 体素 → **54,486 三角形**。
- `MeshBasicMaterial + vertexColors`：顶点色即全部光照，动态元素（火光/涟漪/震颤）
  纯叠加，不改变静态件离线在线一致性。

## 交互

- **候震**：点龙首 / 数字键 1–8 → 都柱倾、杠杆沉、颚开、丸落、蟾衔（涟漪 + 铜声 +
  方位标签「震自·东南·伍级·659Hz」）→ 丸沿八道归位。
- **震级** 1–9（滑杆）：振幅/音量/标签分级。
- **八龙齐奏**（Q）：五声音阶 宫商角徵羽宫̇商̇角̇，每龙一个音。
- **自动候震**（A）：6–14s 随机方向小震。
- **解构**（E）：盖/龙/蟾/柱/杠杆分层展开。
- 轨道相机（拖拽/滚轮/触屏），闲置 4s 缓慢自转；WebAudio 合成铜声（泛音列 + 敲击
 瞬态 + 低频震感），M 静音。
