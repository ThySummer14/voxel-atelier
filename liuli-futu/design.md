# 《琉璃浮屠》· 体素巨作设计书（Blender 版）

## 1. 概念

**作品名**：《琉璃浮屠》
**副题**：The Glazed Stupa of the Void

**参考物**：敦煌/应县琉璃塔意象 × 星渊悬浮仙山——一座九层琉璃浮屠自晶岩浮岛拔起，塔心吐出光柱刺破星云，灯瀑坠入虚空。既非游戏关卡也非建筑白模，而是**可多机位凝视的博物馆级体素神殿**。

**语气**：庄严、通透、神圣的光。与《北冥载山》的「负重航行」相反，这里是「向上刺破」。

**一句话锁调**：*Glazed-emissive voxel stupa × volumetric god-rays × cosmic crystal island*

## 3. 结构清单

1. **晶岩浮岛**：倒锥岩基 + 晶簇尖 + 苔顶 + 石径
2. **九层琉璃浮屠**：逐层收分；每层墙/透窗/柱/平座栏杆/重檐飞角/檐角灯
3. **塔心光柱**：自宝顶向上的体积光束（Volume）
4. **灯瀑**：3 股发光水帘坠入虚空
5. **配景**：侧亭、连桥、墨松、浮云、碎晶
6. **大气**：星场、星云、体积雾

## 4. 渲染规格

- Blender 5.2 Cycles + OpenImageDenoise
- 2560×1440，128–256 samples
- 体积光（宝顶光柱 + 环境薄雾）
- 三机位：全景 3/4、仰视近景、俯视总览
- 另存 `.blend` 可继续编辑

## 5. 签名瞬间

1. **光柱刺夜**：宝顶光束切开星云
2. **万窗灯暖**：九层窗火层层递上
3. **飞檐鎏金**：角翘与金饰在侧光里勾边
4. **灯瀑坠渊**：发光水帘从岛缘坠落

## 6. 优先级

**必须**：完整浮岛 + 九层浮屠 + 光柱 + 灯瀑 + Cycles 成片
**加分**：体积光、晶簇、多机位、blend 可编辑
**不做**：音频、角色动画
