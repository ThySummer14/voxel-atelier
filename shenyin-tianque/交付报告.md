## 一、艺术与技术架构概览

本项目融合中式唐风重檐楼阁与吉卜力浪漫奇幻神话意境，构建水天一色的神明灵域。

```
神隐天阙 (The Celestial Bathhouse)
├── 体素基底与水域： build-base.js (巨石基底、海波浅滩、水中轨道)
├── 八层主楼与飞檐： build-bathhouse.js (朱红外廓、悬空斗拱、唐破风金顶、高空天池)
├── 动力学生灵装置： build-wheel.js, build-props.js (水上列车、盘旋白龙、无脸男、千寻、大水车)
├── 材质与环境系统： ambient.js (三时相光影转换、多频流动水面Shader、车窗蒸汽与夜空流萤粒子)
├── 空间网格引擎：   voxel.js (空间哈希去重、邻域面剔除、4角AO接触阴影烘焙)
└── 交互与后期管线： main.js, index.html, style.css (Three.js r160, UnrealBloom, 电影级运镜系统)
```

## 二、核心特性达成

1. **宏大体量与细节刻画**
   - **419,803 实心体素**：经全向邻接面消除后提炼为 **282,588 个面片**，网格装配耗时仅 **230ms**。
   - **八层楼阁**：包含层层递进的飞檐翼角、悬空阁道、暖黄格栅障子窗、神明题额挂落与千盏朱红灯笼。
   - **动态生灵与装置**：
     - **白龙（赈早见琥珀主）**：在金顶云海盘旋巡弋，身姿随正弦波起伏。
     - **海上红皮蒸汽列车**：在水中轨道破浪飞驰，车顶烟囱实时喷发蒸汽粒子烟雾。
     - **朱红拱桥与神隐生灵**：桥头伫立无脸男与系白裙的千寻，桥下巨型水车平稳转动汲水。

2. **三时相光影系统（Phase Transitions）**
   - **薄暮·神隐（默认英雄相）**：紫红绯霞向深靛蓝过渡，天边金辉斜照，水天镜面泛着琉璃暖光。
   - **华灯·盛宴（夜景华彩）**：深邃星夜，千盏华灯与大红灯笼自发光盛放，流萤点点飞舞。
   - **晨曦·霁空（清冽拂晓）**：晨雾氤氲，天光破晓，水波粼粼。

3. **定制着色器与视觉特效**
   - **自定义水面材质**：多频流动正弦波纹叠加法线扰动，计算视线与天光的镜面高光反射，并与全场景线性深度雾无缝融合。
   - **后期处理**：采用 `UnrealBloomPass` 对发光体素（灯笼、窗火、宝珠）施加柔和梦幻辉光。

## 四、本地启动指南

在项目根目录下启动静态服务器：

```bash
# 1. 启动静态服务器（默认端口 8341）
node .serve.cjs 8341

# 2. 打开浏览器访问
http://127.0.0.1:8341/
```

- **鼠标交互**：左键拖拽旋转视角，右键平移，滚轮平滑推拉。
- **键盘操作**：`Space` 空格键可随时暂停/恢复场景内动态生灵与列车运行。
- **面板控制**：点击底部胶囊按钮可无缝平滑切镜（全景、红桥、天阁、车行、俯瞰）与切换光影时相。
