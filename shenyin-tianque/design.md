# 《神隐天阙》· 概念与技术设计书
# The Celestial Bathhouse of the Spirit Realm

> 「逢魔时刻，海潮退作明镜，水上列车破浪而至；
> 　千寻朱桥之上，万盏华灯初醒，神明入汤，天阙隐于云海。」

---

## 1. 概念与世界观定位

- **作品名**：《神隐天阙》（The Celestial Bathhouse）
- **核心意象参考**：吉卜力《千与千寻》神明油屋 × 浮空水上列车 × 东方海上天阙神殿。
- **美学基调**：
  - **华丽与神秘并存**：朱红金漆重檐楼阁、层叠错落的歇山顶、唐破风金门首、大红灯笼连绵、水上朱桥横跨水天。
  - **第一眼视觉极致震撼**：冷暖对撞（紫红暮天/深靛星海 对比 暖黄万灯与朱红殿宇）、水天一色的天空之镜倒影。
  - **生动细腻的电影级叙事钩子**：
    1. 水上红色复古蒸汽列车正穿过朱桥下方的水轨破浪进站，烟囱喷吐体素蒸汽粒子。
    2. 朱桥之上，无脸男静静伫立，侍者提灯迎候；露台之上，神客凭栏举杯，白萝卜神在顶层天池惬意蒸腾。
    3. 天阙最高檐角之上，一尾银鳞青鬣的体素飞龙（白龙）盘旋缭绕，龙须微拂。
- **与过往作品的代际飞跃**：
  - 彻底打破《浮岛茶庭》(7分)的微缩孤立感，提供极其宏大且层次分明的神话立体场景。
  - 彻底解决《青绿千里》(4分)远景如电视雪花、色调灰暗、缺乏生活细节的硬伤，做到**远观气势磅礴，近看细节如画**。
  - 继承《上河虹桥》成熟的暖阳阴影与市井动感，但提升到神话奇幻与奢华美感的巅峰。

## 3. 场景要素清单（万象齐备）

1. **主天阙（油屋神阁）**：
   - 八层递进收分结构，层叠挑檐、转角起翘斗拱。
   - 正门挑空「唐破风」弧形金顶门首，高悬「天阙」金匾。
   - 侧翼连廊、错落望楼、顶层观星露台与巨型八角主阁。
   - 巨大转动水车（巨型木构水轮，汲水入汤池）。
   - 露天金汤温泉池，白色热气蒸腾。
2. **凌波朱桥与水上铁道**：
   - 红色多跨长桥，连通彼岸鸟居与油屋大门，两旁陈列红灯笼望柱。
   - 桥侧平行的水下/水面双轨铁道，枕木在浅水中隐现。
   - 红色水上单节蒸汽列车：车身亮红、车顶烟囱升腾白雾粒子、车窗透光、车头暖灯探路。
3. **生灵与客群（神话登场）**：
   - 朱桥桥头：黑袍面具的「无脸男」与提红灯的「侍客仙童」。
   - 天阙入口：迎客青蛙杂役与巡视管事。
   - 三层露台：数位凭栏举杯赏景的异界仙客（鸟首仙人、花冠仙娥）。
   - 顶层汤池：惬意泡澡的「萝卜神」露出白色圆润身躯与青翠菜叶。
   - 盘旋白龙：银白修长龙身、青色龙鬃与双角，沿天阙后檐自云端蜿蜒探出。
4. **大气与自然系统**：
   - 浅水镜面（自定义水面 Shader，深浅流动、列车推开的尾波涟漪、金色落日反光）。
   - 水天交界处的朱红大鸟居与远山云海。
   - 三时相昼夜系统：
     - **薄暮·神隐（默认英雄相）**：紫红渐变落霞、夕阳长影斜切红桥、百窗初明。
     - **华灯·盛宴**：深蓝星河降临，千盏朱灯全盛点亮，强 Bloom 托出流光溢彩，萤火星散。
     - **晨曦·霁空**：澄澈青金晨光，朝雾缭绕，仙气扑面。
   - 粒子系统：列车蒸汽白雾粒子、汤池袅袅仙气、夜空流萤星尘、落英花瓣。

## 4. 技术规格与性能指标

- **管线**：纯原生 JavaScript ES Modules + Three.js r160 本地库，无任何构建打包与外部网络请求。
- **体素内核**：
  - 稀疏空间哈希 Map(x|y|z) → 面剔除（Face Culling）→ 四角 AO 顶点烘焙（曲线 [0.55, 0.74, 0.90, 1.0] 翻转三角对角线以消除条纹）。
  - 分离材质世界：
    - `solid`：Lambert + 顶点色（sRGB→Linear 预校正）+ 4096 PCFSoft 阴影。
    - `glow`：高亮度 Basic 自发光，配合精确 UnrealBloomPass 泛光阈值。
    - `water`：自定义动态 Shader 镜面水体，集成菲涅尔反射、流动波纹与雾效集成。
- **运行指标**：
  - 体素数：约 120,000 ~ 160,000 体素，精炼剔除后约 130,000 ~ 180,000 四边面。
  - 构建时间：浏览器纯 CPU 生成 < 300ms。
  - 帧率：稳定 60 FPS，Draw Call 控制在 25 以内。
  - 零报错、零警告、支持窗口自适应与高分屏优化。

## 5. 验收标准

1. **第一眼美感（Hero Shot）**：
   - 画面气势磅礴，色彩浓郁饱和但极具东方典雅韵味，冷暖光影剧烈张力。
   - 朱红建筑与金色华灯从天水之间脱颖而出，没有一处灰暗脏乱。
2. **生动性（Movement）**：
   - 列车在水面稳步前行，烟囱蒸汽自然腾起消散。
   - 水轮持续转动，温泉热气袅袅上升。
   - 白龙龙首随波微动，神话生灵细节耐人寻味。
3. **交互体验**：
   - 4 个高画质电影机位顺滑过渡（全景神隐 / 桥心过车 / 正门盛宴 / 露台望月）。
   - 支持自由拖拽轨道环视、滚轮缩放、双击还原。
   - 支持时相自由切换（薄暮 / 华灯 / 晨曦）及自动巡航。
