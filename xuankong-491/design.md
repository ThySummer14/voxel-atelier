# 工程与造型规范 · 《悬空千仞 · XUANKONG 491》

## 1. 实物参考基准（山西大同浑源县 · 恒山金龙峡翠屏峰悬空寺）
- **历史始建**：北魏太和十五年（公元 491 年），现存建筑主要保存明清重修木构规制，全寺面朝东偏南，嵌于翠屏峰西侧赤褐色刀削绝壁的天然凹槽（石窟腹地）之内。
- **真实地形与选址智慧**：
  1. **上凸如伞盖**：悬空寺正上方岩壁向外挑出约 8–12 米，形如巨型石伞，使古寺千年免受雨水冲刷与落石砸击。
  2. **两边突岩环抱**：南北两侧山岩外凸，阻挡峡谷狂风；由于深处峡谷，全年日照极短（日均仅约 2 小时晨光直射）。
  3. **下临深渊与摩崖**：寺下为唐峪河（金龙峡碧涧），水畔巨石镌刻相传唐代李白手书「**壮观**」（其中「壮」字多一点，意喻比壮观更壮观）。
- **核心建筑力学（「半插飞梁为基，巧借岩石暗托」）**：
  1. **铁杉横梁（飞梁）**：选用当地特产铁杉木，经桐油浸泡防腐防虫；直径约 30–50cm 的方圆木梁，**约 2/3 长度深凿入崖壁石孔内**，孔内端部打入木楔（膨胀锚栓原理），越受力咬合越紧；外挑 1/3 承托殿宇楼板。
  2. **立木支承柱**：崖壁下方的细长竖向木柱（直径约 15–25cm），并非盲目乱撑，其中一部分压实于下层岩石凸台分担弯矩，另一部分在无荷载时微悬、仅在上层站满香客楼板微沉时才真正吃力，形成刚柔并济的超静定木构体系。
- **建筑总体格局（「一院两楼」，自南向北步步升高）**：
  1. **南端山门与登云石阶**：依托南侧岩阶凿石筑台，朱漆山门牌楼与护墙。
  2. **南院（双层主院落）**：底层纯阳宫/三官殿（贴崖石窟与外挑前廊结合），二层千手观音殿，南北两侧配以对称凌空的**钟楼**与**鼓楼**（重檐歇山十字脊顶，绿琉璃剪边灰筒瓦）。
  3. **南楼（三层高阁）**：紧贴绝壁逐层内收外挑，底层萨迦殿、二层伽蓝殿、三层送子观音殿，雕花朱红勾栏、雀替、斗拱层叠。
  4. **双层凌空飞栈（长虹栈桥）**：连接南楼与北楼的标志性窄险栈道，宽度仅容一二人侧身，下层通往内窟栈廊，上层直抵北楼二层，脚下镂空直望百米深涧。
  5. **北楼（最高最险三层危楼 · 三教殿）**：全寺视觉最高潮，底层四佛殿、二层三圣殿、顶层**三教殿**——殿内正中释迦牟尼（莲台金身）、左孔子（冠冕拱手）、右老子（道髻拂尘）三教始祖同堂端坐，重檐歇山琉璃脊兽凌空欲飞。

## 2. 体素空间网格与比例尺设计
- **单位比例**：`1 体素 = 0.25 米`（即 25 厘米分米级精雕网格，可细腻刻画斗拱挑头、飞檐举折、琉璃剪边、栏杆寻杖与蜀柱、铁杉飞梁断面、木楔与人物衣袂）。
- **世界包围盒（Voxel Grid Bounds）**：
  - `X`（峡谷进深：西侧深山崖腹 → 绝壁立面 → 凌空楼阁 → 东侧河滩古道）：`[-64, +96]`（共 **160** 格 = 40 米剖面进深）
  - `Y`（天地垂直高度：河床基岩 → 碧涧水面 → 摩崖巨石 → 下悬立柱 → 三层飞阁 → 倒悬伞盖危崖 → 崖顶古松苍穹）：`[0, 264]`（共 **264** 格 = 66 米垂直高差，呈现极致悬空惊险感！）
  - `Z`（南北走向：南端登云山门 → 钟鼓双楼院落 → 南楼 → 凌空双层栈道 → 北楼三教殿 → 北侧峭壁飞瀑）：`[-128, +128]`（共 **256** 格 = 64 米横向展宽）
- **总网格容量**：`160 × 264 × 256 = 10,813,440` 体素单元空间，经精细分层建造与表面/剖面构筑，实心体素约 **80 万～130 万枚**，可见表面经 **Greedy Meshing** 合并后控制在 **12 万～22 万三角面**，确保 1600×1000 Metal WebGL 稳定 **60 FPS**。

## 3. 分组图层与「飞梁力学 X 光剖视模式」架构
为了既能在常规模式下展现震撼完整的绝壁古寺，又能在「**力学剖视（X-Ray Mechanics）**」模式下让评审者一眼看穿悬空寺屹立 1500 年的工程秘密，我们将体素按材质与功能分为五大独立网格组：
1. **`cliffOuter`（外层赤壁危崖）**：常规模式下完整不透明；开启「力学剖视」时平滑切换为半透明线框/琥珀晶石透视态，直接暴露出崖壁内部深凿 2.5～4 米的石孔！
2. **`structuralBeams`（核心承重力学体系）**：桐油铁杉飞梁（深插石孔段 + 外挑悬臂段）、孔端膨胀硬木楔、崖底细长铁杉立木支承柱、斜撑替木。在「力学剖视」模式下自动激发高对比暖金结构高亮与传力流向脉冲光效！
3. **`architecture`（古寺木构、白灰墙、朱漆栏杆、绿琉璃剪边灰瓦、斗拱飞檐、三教塑像）**：精细分材质（粗糙生漆红、风化老榆木、青砖白灰壁、琉璃釉面高光、泥金塑像）。
4. **`lanternsAndGold`（自发光窗棂油灯、殿内长明灯、铜钟与金身细节）**：随昼夜循环自动点亮暖黄辉光。
5. **`natureAndProps`（河床卵石、古道石桥、「壮观」摩崖巨石、崖缝苍松、行旅僧人与香客）**。
