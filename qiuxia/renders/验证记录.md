# 《秋峡》 AUTUMN GORGE · 验证记录

交付物：可交互体素立体透视模型（diorama）。唯一造型参考为真实摄影 `reference/QJ-6884-real.jpg`（前进型 QJ-6884，下关站）。
未参考任何其它体素作品；几何全部由代码生成，声音全部由 WebAudio 程序化合成。

## 打开方式
```bash
cd 秋峡-autumn-gorge
npm install
npm run dev        # http://127.0.0.1:5173
# 或生产构建
npm run build && npm run preview   # http://127.0.0.1:4173
```
交互：拖拽旋转 · 滚轮/双指缩放 · 7 机位按钮（全景/过桥/站台/峡谷/机构/洞口/跟随）· 暂停 · 时间滑杆（昼夜）· 隐藏 UI · 声音开关。
键盘：`1–7` 机位 · `Space` 暂停 · `H` 隐藏 UI · `C` 昼夜自动循环 · `W` 鸣笛。

## 缺陷与修复对照（迭代中真跑发现并修复）
| 缺陷 | 修复 |
|---|---|
| 相机预设穿入山体/煤水车内部（黑屏） | 重算全部机位球坐标，逐一截图验证 |
| 雾过浓发奶白 | FogExp2 密度系数 ×0.5 → ×0.18 |
| 水面平面超出峡谷南切面成蓝线 | 平面内缩 span−4 / NZ−2 |
| 云灰饼/合并成整片云幕遮全景 | Lambert→Basic 提亮；云量 16→8、半径缩小 |
| 洞口像独立门楼 | 世界高 120→140，洞口山体加高加宽（mound 118） |
| 偏心杆方程奇异（C/R<−1，73 相位不闭合） | 偏心杆长 15.5→14.0（落在可达区间 [13.52,14.71]） |
| 联合杆/半径杆长三角不闭合 | 主连杆 34→29、联合杆 6.0→6.8，Newton 范围 ±0.7→±1.0、40 次 |
| 侧连杆枢轴偏移 −MAIN_X（眼位差 46 体素） | 枢轴改设主曲柄销 (px,py) |
| 动轮未做 quartering | 左右曲柄相差 90°，轮枢轴加相位 |
| 机车背光纯黑剪影 | 加相机侧补光 + 炭黑色值提亮 + 跟随英雄机位改前 3/4 |
| 峡谷机位贴桥侧墙/水面 edge-on 白带 | 改谷底仰视拱券机位 |
| 站台机位被机车/雨棚挡 | 截图时把列车移开 + 抬高机位 |
