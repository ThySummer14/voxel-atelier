# 交付报告 · 经天纬地

2026-09-29 交付。题材自选、代码全部新写（未读同级任何其他作品的代码或文档）。

## 是什么

一台**会真的织**的体素花楼提花机。花本（打孔卡）上每一张的孔 = 这一纬要提起的经线；
孔被读卡灯照亮 → 经线抬起开口 → 地梭整幅、彩梭按花纹段挖梭引纬 → 筘摆到织口打紧 →
卷布轴前移、花本进一张。织出来的锦**逐格等于花本数据**。

三本原创花本：落花流水 / 团花宝相 / 星图·北斗，各 60 经 × 42 纬。

  60×42 格，与花本逐格比方向——**三匹布每一格都对**（离线与在线各跑一遍，同一口径）。
- `打纬前棚里的纬线颜色 = 该纬织成色（42 纬 × 60 格）`：飞行途中引到棚里的彩纬，
  在打纬前必须已经是这一纬的成品色。
- `花本卡孔位 = 提综表（3 本 × 42 张全对，每张 ≥3 孔）`：卡片几何与提综表共用一个出口。
- `提起的经线 ⊆ 本纬/上纬花本孔`、`已织纬数单调不减`、`花本带位移不会倒带`、
  `引纬时梭必在梭道内`、`120 段经线与织口高度对位`、`织口与布面上方露天`。
- 网页端：`开织/停机真的停得下来`、`换花本真的换了本子`、`去机架真的隐去了构件`、
  `熄灯开关生效`、`无控制台错误`、`60fps`。

## 体量

- 体素 1,104,714 格；全部件三角 12.5 万（静态 10.9 万，合并率 91%）。
- 一匹 70–99s（×1），另 2.4s 成匹停顿 + 2.8s 落机；速度 ×½–×4 + 整匹快进。

## 签名看点

1. **花本带**：42 张卡吊在花楼后段，孔带正对经线，背后背光板——**孔亮实黑**，
   光穿过孔就是这一纬的提综。两端卷轴随进度转动、卷径变化。
2. **织口**：60 根经线逐根抬起开口；地梭整幅掠过，彩梭按花纹段就地出、原路回；
   彩纬在棚里一段段积出来，筘一摆整行推入织口。
3. **落机**：成匹后整匹平板从织口翻立、飞到晾锦架挂好（行 0 在最上），换下一本。

## 已知未验 / 没做的

- 真机浏览器（Chrome/Safari/Firefox）、移动端触屏、真实 GPU 帧率（headless 软栅格下 60fps）；
  声音只在无头环境起过，音色没在真机听过。
- 没做：多人协作、导出 GIF/MP4、纹理贴图（本作刻意全顶点色）、任意尺寸自定花本
  （花本现在是代码里的生成器，不是外部文件）。
- 视觉取舍：夜景偏暗是刻意的（月色 + 一盏油灯 + 花本背光）；若嫌暗，
  `js/spec.js` 的 `LIGHT` 里 `skyUp/skySide/sunI/lamps[0].I` 就是全部旋钮。
