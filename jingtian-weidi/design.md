# 设计说明 · 经天纬地

## 0. 为什么是提花机

体素是「一格一格垒起来」的，《千里江山图》一类题材自然落进山水楼阁；
而**提花机**是把「一格一格」写进机器里的东西：花本上打孔/不孔，就是一纬里经线提起/不提起，
织出来的锦于是逐格等于花本数据——它就是最早的穿孔程序、计算机的祖先（雅卡尔织机 → 打孔卡 → 二进制）。
体素这门媒介的「逐格」在这里不是外观，而是**机制本身**：这是本作选它的理由。

## 1. 编织机制（可被断言的部分）

- **经**：60 根素色（按花本染地色）经线，间距 2 格，幅宽 120 格；经面高度 y=36。
- **纬**：每纬 = 地梭一整趟（通梭，整幅）+ 若干彩纬段（挖梭，小梭就地出、原路回）。
- **地组织**：3/1 斜纹——地格按 `(i + 2j) % 4 === 0` 提起（经浮，露经色），其余纬浮（露地色）。
- **花**：花格一律**不提经**，彩纬压在经上（露花本色）。
- 于是「花本孔集 = 提综表 = 挖梭段」三者同源；织成的布 = `topColor(花本)`。
  这条链路有三重断言：离线逐格（7560 格全覆盖，与「期望色×该格光照」比方向）、
  在线逐格（同一口径）、以及每纬打纬前棚内纬线颜色 = 该纬织成色（42×60 格）。
- **时序**（一纬）：提综 0.18s → 地梭 0.06+0.04+0.005·格 → 每彩梭段 (0.06+out+0.5·out+0.06) →
  打纬 0.26s（筘从静止位摆到织口，把棚里的纬线推到位）→ 卷布/花本进 0.08s → 歇 0.03s。
  单纬 0.9–3.0s，一匹 70–99s，另有 2.4s 成匹停顿 + 2.8s 落机。

## 2. 织机结构（真做出来的部分）

- 机架：四柱（前柱只到侧梁，织口通透）+ 侧梁横档 + 斜撑 + 踏杆踏板。
- 花楼：后段木楼 + 悬山小顶（只披在经轴上方）；**60 根提花线束**自综眼上方升至 y=96，
  折成阶梯斜线挂到花本带的提花子上。
- 花本带：42 张卡，卡面在 z=-30，孔带正对经线（孔 = 提起的经线），背后一块背光板——
  **孔亮、实片黑**，所以「读花本」是看得见的：光穿过孔，就是这一纬要提起哪几根。
  两端各一卷（未读在右、已读在左），随织造转动、卷径随进度变化。
- 筘：框 + 61 片箅齿（齿距 2，经线从齿间穿过）+ 两根吊臂，绕打手轴（y=112, z=-2）摆 −0.172 rad 打纬。
- 三轴：经轴（放经，会转）、胸梁（固定，顶面与经面齐平）、卷布轴（卷布，会转）。
- 五把梭：梭身 + 可缩的丝线团（各色按用量缩），停在右侧梭架上；引纬时掠入梭道、
  沿段飞行（引纬）或抬梭回位（不引纬）。棚内纬线按覆盖序长出来，打纬时整行推入织口。
- 落机：成匹后整匹平板从织口翻立、飞到晾锦架挂好（行 0 在最上），换下一本继续。

## 3. 光照与画法

- **全烘焙**：天光（按法线的冷底光 + 向上抽样遮蔽）、日光（方向光，逆光行走逐格硬投影）、
  两盏点光（油灯暖主光 / 读卡灯），AO 四角走经典体素 AO，全部乘进顶点色。
  离线软光栅器与浏览器共用 `js/voxel.js` 与 `js/spec.js` 的同一份常数，**离线所见即交付所见**。
- 织机上方开天井（z −62…72 露天），月光直接落在经面与布上；前庭也露天，屋面只覆后段——
  这是为了让「布上一格一格的锦」在夜里读得出来，也让高机位不被屋面挡住。
- 花本带与提花线束的位置是按「窗外月光通路」反推的：从布面逆光走，会在 (x−72,y117) 撞到花楼顶、
  在 y≈99 撞到线束。故线束止于 y=96 再折向 z=−30 的花本带，布面才拿到干净的光（无条状阴影）。
- 无 SSAO / Bloom / DOF / 阴影贴图；暗角与暖晕是 CSS 的 `mix-blend-mode` 薄纱。

## 4. 三个花本

| 本 | 地 | 花 | 骨架 |
|---|---|---|---|
| 落花流水 | 石青 | 金浪 / 玉浪花 / 朱玉落花 | 两道长浪（周期 150）+ 六朵六瓣落花 |
| 团花宝相 | 绛 | 金瓣玉尖 / 朱心 / 玉缠枝 | 一大团花（R=16.5，五瓣）+ 上下缠枝 + 角云 |
| 星图·北斗 | 靛 | 淡青星河 / 月白星晕 / 银白亮星 / 暗金连线 | 三道星河 + 北斗七星连线 + 散星 |

- 花纹在**体素纵横比**坐标里生成（格 i → u=2i−59），圆就是圆。
- **织造经济性**：每纬彩纬段数（= 小梭往返次数）≤ 9，均值 3 左右；段数由花本生成器控制，
  `patterns-report.mjs` 逐纬打印。每纬强制留 ≥24 格地组织——否则无经可提、无梭可过。
- 期望布面 `expectedCloth()` 与 3D 布面着色 `topColor()` 是同一函数，杜绝两套说法。

## 5. 交互与声音

- 点织机开/停；点花本带换本；六机位（全景/织口/花本/花楼/晾锦/侧视）；速度 ×½–×4；整匹快进；
  「去机架」看骨架、「隐线束」看经面、「熄灯」只剩月色与花本背光。
- 音效全部 WebAudio 合成：打纬闷响（三角波下滑 + 噪声头）、梭风（带通噪声扫频）、
  花本棘轮（方波咔哒）、落机磬声（三声五声音阶）、屋内底噪（低通噪声）。首次点击才起声。

## 6. 离线工具链

- `raster.mjs`：自写软光栅（透视 + z-buffer + 透视校正插值 + 近平面裁剪 + 超采样 + 自写 PNG 编码），
  吃的是同一份几何与顶点色，用来秒级看图与摆机位。
- `accept-node.mjs`：不碰浏览器的真值断言（59 条）。
- `accept-web.py`：playwright 起真页面（`--use-angle=metal`），断言场景、逐帧采样、布面实测、
  交互生效、帧率、无控制台报错（18 条）。
- `shoot.py`：12 张全页出图 + manifest（含 FPS）。

## 7. 走过的弯路（留作教训）

- **日光法线取反**：`nd = n·sunDir` 用的是光行方向，朝上的面因此全在黑里，窗光斑一直"看不见"；
  改成 `——n·sunDir` 后月光才真的落在经面与布上。
- **晾锦架立柱**立在画面中左、**后墙墙柱**立在 x=0，两条黑柱把全景切成两半：立柱改细、墙柱挪到 ±42。
- **花本带原在 z=−6**：卡片与线束正好挡在布面的月光通路上，会在锦上打出 1 格宽的条影。
- 布面比色的判据不能贪方便：贪心合并会把相邻两纬合成一个面片、彩灯会把色度整体拉偏；
  最终口径是「顶面片按面积栅格化回 60×42 格，再与 期望色×该格光照 比方向」。
- 段数统计一度把「素白经浮」也算成换色（斜纹每 4 格一个白点）→ 一纬 45 段、整匹要织十分钟；
  素白是提经得来的、不飞梭，只按纬色统计才对。
