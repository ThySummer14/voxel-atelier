# 《青绿千里》交付报告（第二轮：缺陷审计与修复）

北宋王希孟《千里江山图》的体素转译：原生 HTML/CSS/JavaScript + Three.js r160，无构建步骤、无远程运行时请求。

本轮是在上一轮「全绿交付」的基础上做的一次**缺陷审计**：逐条读源码 + 逐张看渲染图，
找出静默失效、恒真断言与画面读不出来的地方，然后修到能跑、能看、能证。
结论先说：**上一轮的验收里有两处是假的，而它们恰好遮住了这件作品最核心的一条交互。**

---

## 一、本轮发现并修好的缺陷

### A. 静默失效（不报错、不掉帧、画面看着也还行）

| # | 缺陷 | 后果 | 证据 |
|---|---|---|---|
| A1 | `patch()` 的 `onBeforeCompile` 替换目标写成 three **展开 `#include` 之后**才存在的 `diffuseColor.rgb *= vColor;`，而该回调拿到的是展开**之前**的原始 shader | **「三矾九染·重新显形」从来没真的落过一次色**：只有 `discard`（擦除/显形）生效，`dyeStage()` 一次都没执行，染色动画只是把山擦掉再原样变回来。顺带 `pow(vColor,2.15)` 的 sRGB→linear 校正也一直没生效，全卷亮部偏灰 | 修前 `dye=0.20` 与完成态的饱和像素色相差 ≈0°；修后 27.5° → 103.7° → 128.5°，与完成态差 **101°** |
| A2 | `LAMP_CORE` 材质从未被写入世界 | `emitCore` 分组恒 0 面，对应材质、`byKind` 项、装配分支全是死码；夜里一百多盏灯是同样大小的一颗点，bloom 吃不到面积 | `measure.mjs` 修前「细·发光芯 0 面」，修后 129 面 |
| A3 | 灯芯若被自己的光晕六向包死，面剔除会把芯剔成 0 面 | 「加了灯芯但 emitCore 还是 0」——第二层坑 | 光晕改为只铺四侧、留顶底 |
| A4 | 夜航「入夜程度」用 `1-(el+6)/18` 从太阳仰角反推，渔火那一格 el=12 恰好算出 **0** | 深夜的江面仍是白天的薄荷绿；水面倒影分支永远不进 | 改为直接取时辰表的 `max(star, lamp)` |
| A5 | `smallBridge` 的法线写成 `-dz / L`，而 `dz` 已是每步增量 → 法线长度约 1/L | 四座小桥（小桥/板桥/草桥/野渡栈桥）**实际只有 1 格宽**，横向取整全落回同一格 | 改为单位方向的垂线 |
| A6 | 长桥桥亭角柱偏移写成 `dx * sx * 0` | 四根角柱两两重合成两根，桥亭读成一根门框 | 恢复纵向偏移 |
| A7 | `beast()` 的四条腿写成 `[[-2,0],[2,0]]` 且每对里两次 `g.set` 落在同一格 | 十三头牲畜只有两条腿 | 改为 `[±2,±1]` 四角 |
| A8 | 双体脚踏船的船员 `ly=3` 落在船舱（y=2..4）内部 | 船员埋进船体，看不见 | 移到两舷甲板，游船/帆船船员一并重排 |
| A9 | 粗格块 X 分段判据 `wx + cell < x0 \|\| wx > x1` | 跨边界的块**同时输出到相邻两段**：重复面，云/雾这类透明层还要双重混合 | 改为按块原点唯一归属；远峰/云/雾各减掉一批重复面 |
| A10 | 瀑布每叠固定画约 27 格高的帘，而本卷相邻列真实落差只有 1–3 格 | 半条帘埋进山体，露出的部分在山腰拼成**一道惨白的梳齿**（深远章实拍） | 帘高改为该段累积的真实落差；缓段只留一道溪面 |

### B. 恒真的验收（上一轮的「全绿」有一部分不是证据）

| # | 假绿 | 为什么恒真 | 现在怎么量 |
|---|---|---|---|
| B1 | `QL.scrollPath` 的 `startCm / endCm` | 探针里**硬编码** `startCm: 0, endCm: 1191.5`，`accept.py` 再断言它等于 0 / 1191.5 | 取自页面真正显示的那行读数文本 |
| B2 | `minClearance > 3.5`（「无穿模」） | 展卷机位 z=322，而世界只到 `WORLD.z1=190` → `terrainTop` 永远返回 −1 → 净空恒等于相机高度 92 | 如实报告 `outsideWorldSamples`，另加沿相机→目标射线的 `buriedSamples / blockedSamples` |
| B3 | D6「染色五阶段」 | 只量了相邻截图的非零像素比例——而 A1 之下色根本没变，几何在增减也会让它通过 | 遮住天与水，只量山体在 `dye=0.20 / 0.45 / 完成态` 的**饱和像素平均色相**与平均 RGB 位移 |
| B4 | `shot.py --still` | `QL.spin(false) && QL.play(false)`：前者返回 `undefined` 使 `&&` 短路，**自动展卷从来没被停掉** | 拆成两条独立语句 |
| B5 | 探针跑完留在卷尾 | `scrollPath` 不复原机位，后续量测全在错误机位上做 | 探针进出各存/还原一次相机、目标、fov、卷位与播放态 |

新增 `QL.shaderProbe()`：把「每一处 shader 注入是否真的命中替换目标」做成硬检查（D6 前置）。
这类失效不报错、不掉帧、画面也说得过去，只有把注入结果本身暴露出来才拦得住第二次。

### C. 画面读不出来（逐张看图得到的）

| # | 症状 | 根因 | 处理 |
|---|---|---|---|
| C1 | 三重远峰在所有分镜里读成**灰白色的现代楼群 / 电视雪花**，「读画」模式下更明显 | ①「顶格深色、其余浅色」→ 横视几乎只看侧面 → 整片浅灰还带暗盖；②沿 X 连续铺满 → 一堵墙；③兰伯特光照让每块有顶亮侧暗的体积反差；④ FogExp2 在亭午密度下 1000 格只吃掉 3% | 按**绝对海拔**统一分色（脚没雾白、淡墨收顶）+ 低频岛链掩码切成一座座山岛 + 山脚补一层蛤白雾带 + 改 `MeshBasicMaterial` 不吃光 + 专用线性浓雾 `uFarFog` |
| C2 | 谷雾在山腰拼成白色梳齿 | 单层 3 格薄片侧看就是一排竖刀片；`DoubleSide` 又正反各混一次 | 堆 3–5 层自下而上渐稀，改 `FrontSide`，不透明度 0.34 → 0.22 |
| C3 | 缓坡整片读成**人工草皮**（深远章最重） | 高频细节噪声最短波长 5.2 格、幅度 ±0.8，取整后每 5 格翻一个 ±1 台阶 | 波长加倍、octaves 3→2，量化前按坡度加权做一次 1-2-1 低通 |
| C4 | 岸坡读成一架**棕色梯子** | 顶面下两格的立水一律压成 `OCHRE_DK`（每级台阶镶一条深棕边）+ 滩涂 60–68% 取赭石 + 陡壁判据 2.4 被台阶化自己触发 | 立水继承本列色带色；陡壁判据 2.4→3.1；滩涂赭石降到 30% |
| C5 | 满山**棒棒糖 / 十字架**，且石青山头也长树 | `clump()` 是竖直半径比横向还大的球；`pine()` 层间距大于层厚 → 串在杆上的圆盘；密度阈值反了（越高越密） | 压扁团块、层与层互相搭住、加一类杂树错开读法、山头基本不长了；采样格点抖动加大到 >1 个格距以打散隐形网格 |
| C6 | **「入画」章一个人都没有**，画面是木柱底面 + 瓷砖一样的水面 | 机位 (60, 9.5, 96) 正落在临水榭 (x=66, z=96) 的柱子底下——而这一章的全部论点是「人四格高是全卷唯一的尺子」 | 移到卷首渔村岸侧，屋宇面阔与人物同框；另给每个村口补 4 个迎面的人（旧版人物只撒在屋后） |
| C7 | 「长桥」章 32 跨被压成一根竖条 | 机位沿桥轴看进去 | 改为侧向平视 |
| C8 | 「渔火」章几乎看不到火 | 只有单格灯 + A4 的入夜恒 0 + 水面上没有任何反光 | 灯芯 + 四侧光晕、就近 8 处渔火的水面倒影（镜像点 + 沿视线拉长 + 波纹抖动）、夜档整体提亮、bloom 收敛 |
| C9 | 低机位下近水是一块**薄荷绿瓷砖地**，「江面留白」没实现 | 水色从 240 格才开始掺绢色 | 起退点 70 格，近岸水色本身改淡（绢底掺汁绿），墨线勾水加对比 |

### D. 性能与内存

| 项 | 修前 | 修后 |
|---|---:|---:|
| `buildMeshes`（Node） | 3366 ms | **2050 ms（−39%）** |
| 浏览器内 Worker 构建 | 2.85–3.17 s | **1.7–1.8 s** |
| 四边形 / 三角形 | 1,847,121 / 3,694,242 | **1,572,531 / 3,145,062（−15%）** |
| CPU 几何属性估算 | 183.2 MB | **156.0 MB** |
| Node RSS | 455 MB | **397 MB** |
| 浏览器 JS heap | ≈202 MB | **≈169 MB** |

做法（都不改画法）：
- 网格化从「每个分段对同一个 Grid 调 11 次」改成**一次遍历、按材质查表多路输出**（193 万体素不再被访问 2100 万次）；
- `forEachVoxelX` 走**按 chunk-X 建的二级索引**，不再每次从头扫约 6 万条的 chunk Map；`forEachChunk` 不再反解打包键；
- 邻格查询走跳过 `Math.floor` 的整数快路径（每面 1 次 + 每角 3 次 AO，量级在千万次）；
- 删掉两个**从未上传、从未被读取**的顶点属性 `gloss`/`reveal`（≈22 MB 与 1500 万次 push）；
- 1100 万个索引从普通数组（V8 里是 88 MB 的 double 数组）改成定长增长的 `Uint32Array`；
- 每体素 7+ 个临时数组（`diag`/`dn`）与每面 1 个 `ao` 数组提到循环外复用。

### E. 健壮性与工程

- `webglcontextlost` 只弹提示不停帧循环 → 每帧再抛一次 GL 错误刷满控制台。现在真正停下来。
- 构建 Worker 的 `onerror` 静默降级 → 现在在载入条上写明「后台不可用，退回本机雕刻」（不打 console，避免污染 D2 计数）。
- 删除零引用死代码：`Grid` 的 `field/box/shell/hollowBox/edges/ellipsoid/cylinder/profile/bounds`（其中 `shell` 与 `hollowBox` 函数体完全相同）、`octR/octFace/mirror8/rotXZ/hash2`、`palette` 的 `MAT/MAT_COUNT/SLOPE_BANDS/CLIFF_BANDS/BIRD/m.lit`、`score.GROUP_ANCHORS`、`blocks.js` 里没用的 `CORNERS`。
- 新增 `tools/shoot-all.py`：一次起一个浏览器把 13 张成片全截完（30 秒），每张带 JSON sidecar 记真实 GPU / draw calls / 探针色相。此前每张都要重建一遍 180 万体素，调机位与配色没法迭代。
- 新增 `QL.pick(x, y)`：屏幕像素反查射线，返回命中的分组、世界坐标与顶点色。「这块白到底是什么」这类问题靠猜要猜半天。

## 四、验收命令

```bash
npm test                      # node --test tools/geometry.test.mjs
node tools/accept-node.mjs    # D3 体量 / D5 峰高 / D9 桥·寺观·围墙
node tools/measure.mjs        # 真实几何与内存
node tools/stats.mjs          # 高度场扫描（--carve / --sweep）
python3 tools/serve-and-accept.py   # 起服务 + 浏览器全链验收（含 D6 两项新检查）
python3 tools/shoot-all.py --out renders     # 一次起浏览器出 13 张成片 + manifest
python3 tools/shot.py output/x.png --w 1600 --h 1000 --chapter 3 --still --manifest --measure --min-fps 50
```

工具失败一律返回非零退出码。

## 五、仍需真机验证的边界

- Safari / iOS Safari 的 WebGL2、HalfFloat、MSAA、context lost 与内存行为未跑真机。
- Android Chrome 与真实低端 GPU 未跑；手机证据是 320/375 viewport + Apple M5 headless Metal，不是手机芯片。
- Firefox / WebKit 自动化矩阵尚未建立。
- Service Worker 需在正式 HTTPS 域名下做首次安装与离线更新验收。
- 本轮模型已能直接读图，C1–C9 的症状与修后对比均由人眼（我）看图判定；但「好不好看」仍建议以 `renders/` 为准由你复核。
- 远峰改画法后粗格块从 16.9 万降到 6.8 万（岛链掩码所致）。若你更想要连绵的远山墙而不是山岛，把 `scene.js` 里 `island < 0.47` 的阈值调低即可，其余不用动。
